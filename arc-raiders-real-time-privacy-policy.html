Política de Privacidade

Arc Raiders Real Time

Última atualização: 19 de agosto de 2026

1. Visão geral

O Arc Raiders Real Time é um BOT para Discord que exibe condições de mapa do jogo ARC Raiders. Esta política explica quais dados são usados e como eles são tratados.

2. Dados utilizados

Para funcionar, o BOT armazena somente dados técnicos de configuração do servidor:

  • ID do servidor Discord;
  • ID do canal escolhido para publicar o painel;
  • ID da mensagem de painel criada pelo BOT;
  • Preferências visuais do painel, como cor e emoji de evento.

O BOT não armazena mensagens, mensagens diretas, nomes de usuários, e-mails, senhas, tokens ou conteúdo privado de membros.

3. Uso dos dados

Os dados técnicos são utilizados exclusivamente para publicar e atualizar o painel de condições de mapa no canal configurado de cada servidor.

4. Fonte das condições de mapa

As condições de mapa são consultadas no rastreador público oficial do ARC Raiders. O BOT não coleta dados de jogadores, contas de jogo ou partidas.

5. Compartilhamento de dados

O Arc Raiders Real Time não vende, aluga ou compartilha dados com terceiros. O Discord processa as interações do BOT conforme suas próprias políticas de privacidade.

6. Retenção e exclusão

As configurações técnicas são mantidas enquanto o BOT estiver no servidor. Ao remover o BOT de um servidor, as configurações desse servidor são apagadas automaticamente.

7. Segurança

O token do BOT é mantido localmente pelo administrador e não é exibido nem armazenado pelo BOT como dado de usuário.

8. Alterações nesta política

Esta política poderá ser atualizada caso o funcionamento do BOT seja alterado. A versão publicada neste endereço será a versão vigente.

9. Contato

Para dúvidas sobre privacidade, entre em contato com a desenvolvedora do BOT no discord: @fcknunes.

ARC Raiders é uma marca de seus respectivos proprietários. Este BOT é um projeto independente e não é afiliado à Embark Studios.
